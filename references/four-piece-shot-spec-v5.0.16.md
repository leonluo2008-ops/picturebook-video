# 镜头 4 件套规范（v5.0.16 新增 · v8 → v8.1 升级修复补丁）

> **核心问题**: v8.1 动作模板（5 段）升级时丢掉了 v8 模板的「运镜 + 方向锚点」规范 → seedance 默认输出「固定镜头 + 主体原地动」（大雁原地抖翅膀 / 松鼠原地蹬腿 = 不符合运行规律）
> **本文件 = 修复补丁**。Step 5 段 2「主体动作序列」必走镜头 4 件套，缺一必被 verify_prompt.py 拦截（FAIL）

---

## 1. 官方权威：Seedance 2.0 §2 镜头 4 件套

> **官方原话**（Seedance 2.0 官方提示词指南 §2「使用分镜时序」）：
> 每个镜头推荐按以下逻辑组织：
> 1. **运镜或镜头切换方式**：如「全景缓慢推近」/「固定机位」/「镜头切至…」等
> 2. **主体动作与表情**：描述核心角色/物体的关键动作、神态变化
> 3. **位置或空间变化**：说明主体所处的场景、位置或空间关系
> 4. **音频信息**：旁白 / 音效 / BGM

**核心结论**：4 件套缺一不可。v8.1 模板只写「主体动作」(件 2) + 「位置」(件 3 弱)，**漏了「运镜」(件 1) + 「音频」(件 4 在段 5 单独)** = 镜头不动 + 主体原地动。

---

## 2. v8 范本 3 类空间目标（v8 模板沉淀 · v5.0.16 复用）

任何「主体位移方向」必须带 1 个空间目标，否则就是 RP-26a「原地动词陷阱」：

| 类别 | 写法示例 | 适用场景 |
|---|---|---|
| **画面内方向** | `toward the right edge of the frame` / `across the meadow from left to right` | 主体在画面中横向穿过 |
| **出画面** | `exits the frame on the right` / `runs off-screen` | 主体完全离开画面（最干脆的位移终点）|
| **镜头位移** | `camera follows from behind` / `low-angle tracking shot from the side` | 主体持续在画面中但镜头跟拍 = 真实空间感 |

## 3. v8 范本 3 类反模式 RP-26a/b/c（v5.0.16 沿用 · verify_prompt.py R3 已检测部分）

### RP-26a 原地动词陷阱（**根因 #1** · 修法必走镜头 4 件套）

| 反模式（必避）| 正模式 |
|---|---|
| ❌ 「小狗在花丛里欢快地小跑」| ✅ 「小狗从画面左侧跑向右侧」|
| ❌ 「小狗越来越快地飞奔」| ✅ 「小狗跑出画面」|
| ❌ 「小狗在雨中笑着跑过草地」| ✅ 「小狗跑过草地后离开镜头」|
| ❌ 「大雁向右飞行」（**v5.0.15 我们的 BUG 写法**）| ✅ 「大雁从画面左侧边缘飞入、向右上角远端飞去，**队伍由小变大再变小**（由近及远），第三只大雁飞出画面右上方消失在天际」|
| ❌ 「松鼠向右奔跑」（**v5.0.15 我们的 BUG 写法**）| ✅ 「松鼠从画面左侧边缘快速跑入、贴着地面落叶带起翻飞的树叶、四肢高频蹬地穿过画面中央、从画面右侧边缘跑出画面」|

**关键要素**：每个动词都必须带**空间目标**（向 X / 出画面 / 离开镜头 / 追 Y）。

### RP-26b 情绪修饰词陷阱（v5.0.16 沿用 · 已被 v8.1 段 3「旁白-动作对应」吸收）

| 反模式 | 正模式 |
|---|---|
| ❌ 「欢快地」| ✅ 「耳朵竖起，尾巴翘起」|
| ❌ 「笑着」| ✅ 「嘴角上扬（仅当参考图有表情时）」|
| ❌ 「脚步轻快」| ✅ 「腿抬得更高，落地更轻」|

**关键要素**：用 **1 组身体动作** 表达情绪，**不用 1 个情绪词**。

### RP-26c 故事弧缺失（v5.0.16 沿用 · 多镜头 Clip 必走 · 4 步固定结构）

| 镜头 | 节奏 | 主体动作 | 运镜 |
|---|---|---|---|
| 1 出现（开胃）| 短句 | 主体初次出现，姿态相对静止，1 句简单动作 | 广角建立 |
| 2 转折（中句）| 中句 | 主体开始移动，1 句核心动作 + 1 个方向锚点 | 跟拍 / 中景 |
| 3 高潮（中句/长句）| 中长句 | 主体移动加速，1 句多动作（仍带方向）+ 1 组情绪外化 | 加速跟拍 / 低角度 |
| 4 收尾（短句）| 短句 | 主体出画面 / 停下 / 完成动作 | 拉远 / 静止 |

**3 镜头版本** = 出现 + 转折 + 高潮（省略收尾 = 由旁白/TTS 决定）。
**反模式**：3 镜头同方向动作 = 节奏平。3 个「快」动作。✅ 好奇 → 加速 → 跑远 → 消失。

## 4. v8.1 段 2 镜头 4 件套写法（v5.0.16 强制范本）

> **v5.0.16 起，段 2「主体动作序列」每个镜头必走以下 4 件套**：

```
镜头 N（@ImageN + 段 N 旁白「完整旁白文本」）：【件 1 运镜】+【件 2 主体动作】+【件 3 位置空间变化】+【件 4 音频信息（段 5 写）】。
```

### 4.1 范本 · 镜头位移类（推荐用于动态主体）

```
镜头 1（@Image7 + 段 7 旁白「秋天大雁飞，autumn」）：中景平视镜头从画面左侧平稳横移跟拍三只灰色拼贴大雁。三只大雁在蓝天中从画面左侧边缘飞入、由近及远向画面右上角远端飞去，队伍由小变大再变小，翅膀上下扇动形成有节奏的浮动，第三只大雁最终飞出画面右上方消失在天际。
```

**4 件套拆解**：
- **件 1 运镜**：「中景平视镜头从画面左侧平稳横移跟拍」
- **件 2 主体动作**：「翅膀上下扇动形成有节奏的浮动」
- **件 3 位置空间变化**：「从画面左侧边缘飞入、由近及远向画面右上角远端飞去，队伍由小变大再变小……飞出画面右上方消失在天际」
- **件 4 音频**：段 5 单独写「音效：翅膀扇动呼呼声（飞近时强、飞远时弱）」

### 4.2 范本 · 出画面类（推荐用于强位移主体）

```
镜头 2（@Image8 + 段 8 旁白「秋天松鼠忙，autumn」）：中景侧面跟拍镜头从左向右平稳横移。灰色拼贴松鼠从画面左侧边缘快速跑入、贴着地面落叶带起一阵翻飞的树叶、四肢高频蹬地往画面右侧冲刺跑过画面中央、最后从画面右侧边缘跑出画面，蓬松大尾巴在奔跑中左右摇摆。
```

**4 件套拆解**：
- **件 1 运镜**：「中景侧面跟拍镜头从左向右平稳横移」
- **件 2 主体动作**：「快速跑入、四肢高频蹬地……跑出画面」
- **件 3 位置空间变化**：「从画面左侧边缘快速跑入……穿过画面中央……从画面右侧边缘跑出画面」
- **件 4 音频**：段 5 单独写「音效：松鼠爪子快速刨地声、落叶被带起翻飞沙沙声」

### 4.3 范本 · 画面内方向类（推荐用于慢节奏主体如落叶飘）

```
镜头 1（@Image2 + 段 2 旁白「秋天落叶飘，autumn」）：特写固定镜头。多种颜色的拼贴秋叶从画面顶部边缘缓缓飘落、横穿画面中央、向画面底部方向沉落，旋转、翻转、翻面，远近层叠形成纵深感。
```

## 5. 末段约束（v5.0.16 沿用 v8 简洁收尾 · 不堆砌）

### 反模式（v15 模板默认段 4 · 必避）

```
❌ 末帧微动:[主体]定格在[姿态]瞬间
❌ 1s 内至少 1 个动作元素([清单])
❌ 末帧定格前持续微动不得成为定格海报
❌ （隐含「必须微动」反暗示）
```

**根因**：4 句冗余 + 隐含「定格」反暗示 = 模型把「必须定格」当字面执行 = 画面静止。

### 正模式（v5.0.16 简洁收尾）

```
✅ 「镜头持续[核心动作]循环不切断不冻结」
✅ 「画面自然流动有运动感」
✅ 「松鼠刚刚跑出画面右侧，镜头继续向右横移一小段，展示松鼠跑过留下的翻飞树叶和空地，远处小树轻微摇晃，然后镜头缓慢停下，树叶落地逐步静止」（推荐 · 用环境延续动势）
```

**判定口诀**：
- 写完 prompt 必 grep 末帧段落冗余 = 0 处
- `grep -E "末帧定格|末帧微动|不得成为定格海报|1s 内至少 1 个动作元素|定格在.*瞬间" clip*-prompt.txt` 期望 0 命中

## 9. v5.0.16 升级迁移（从 v5.0.15 老 prompt 改起）

**最小修改口诀**（4 步）：
1. 在每个「镜头 N」首句前加运镜动词（横移 / 推近 / 跟拍 / 固定 / 俯冲 / 缓慢推镜）
2. 把所有「向右飞行」「继续奔跑」「在画面中」改为「从画面 X 边缘 Y，向 Z 方向」+ 出画面终点
3. 把所有「保持 X 运动」改为有空间目标的「穿过中央 / 飞出画面 / 跑出画面」
4. 段 4「收尾不凝固」改用「环境延续动势」（远处小树摇晃 / 落叶翻飞 / 镜头缓停）

**验证**：跑 `python3 scripts/verify_prompt.py <prompt.md> --generate-audio`，期望 `ok=true, 0 failures`。
