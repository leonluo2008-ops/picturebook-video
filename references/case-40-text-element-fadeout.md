# 案例 #40 · 多镜头 Clip 装饰性文字元素淡出丢失

> **来源**: Gardenia 栀子花绘本 · 2026-07-19 · v5.0.18
> **根因**: 镜头 2/3 各写一句"保留参考图中的 X 文字" → seedance 把这种"分散镜头内的指令"理解为"局部保留" → 镜头切换时 = 模型自动淡出
> **修复**: 装饰字保留指令**只写一次**在【主体和视觉基底】段 1（作为贯穿整段的全局规则）→ seedance 视为画面元素属性而非镜头级指令
> **沉淀**: 硬约束 #8 + verify_prompt.py R13 执行抓手

---

## 1. 翻车现场

### 1.1 素材

绘本《Gardenia 栀子花》Clip 1（12s, 3 镜头, 16:9）：
- @Image1：深绿蜡笔叶特写 + 装饰字 `gardenia`（彩色字母）+ `栀子花`（深蓝中文黑体）
- @Image2：一朵白栀子花 + 装饰字 `gardenia` + `栀子花`
- @Image3：白栀子花 + 深绿蜡笔叶特写 + 装饰字 `gardenia` + `栀子花`

### 1.2 v1 prompt（翻车版 · 把"保留装饰字"散落在每个镜头）

```
镜头 1（开篇·跟随段 1）：固定特写镜头，从一片深绿栀子叶的特写开始（沿用 @Image1 构图）...
装饰字"gardenia"+"栀子花"以涂鸦风格叠加出现在画面上部中央位置。

镜头 2（跟随段 2）：侧面平视中景，切换至 @Image2 构图，画面中央浮现一朵完整的白栀子花；
花瓣边缘随空气轻微外翻舒展...

镜头 3（跟随段 3）：固定中景，在白栀子花周围伸出 3-4 片深绿蜡笔叶（沿用 @Image3 造型）...

末尾约束：
无水印，无背景音乐。保留参考图中的"gardenia"彩色字母与"栀子花"中文黑体字作为画面装饰元素。
```

### 1.3 实测结果

✅ verify_prompt.py 全绿（无 FAIL，无 R11 空间目标问题）
✅ seedance 任务 `cgt-20260719140010-gr8db` 成功返回
✅ 抽帧 frame_01：装饰字完美呈现（"gardenia"彩色字母顶部居中 + "栀子花"中文黑体）
⚠️ frame_02（@Image2·一朵白栀子花）：**装饰字缺失**——只剩白栀子花主体
⚠️ frame_03（@Image3·花+叶）：**装饰字缺失**——只剩主体
❌ **用户原话**："clip1 丢失了参考图 2、3 中的彩色文字，其它两个 clip 都没有丢失，请检查哪里出了问题"

### 1.4 关键教训

**末尾约束的"保留 X 文字"只能锚定到最后一个镜头**（clip2/3 因末尾约束不切换参考图，所以装饰字全程保留；clip1 切换 3 张图，每个镜头独立发挥 = 装饰字逐段淡出）。

verify_prompt.py **没有任何一条规则检查"装饰字保留指令是否提升到段 1 视觉基底"**——这是 R6-R12 的盲区。

## 2. v2 prompt（修复版 · 装饰字指令提升到段 1 全局规则）

```
【主体和视觉基底】
参考 @Image1、@Image2、@Image3，三图共用同一朵白栀子花与深绿叶的造型语言：纯白玫瑰花型重瓣花，
深绿椭圆形蜡笔叶。背景米黄蜡笔纸质纹理。
**画面元素：自始至终保留参考图中的"gardenia"彩色字母与"栀子花"中文黑体字作为画面装饰元素，
固定在画面顶部居中位置（持续贯穿不淡出）。**

【主体动作序列】
镜头 1（开篇·跟随段 1）：固定特写镜头，从一片深绿栀子叶的特写开始（沿用 @Image1 构图），
镜头缓慢向后拉远...

镜头 2（跟随段 2）：侧面平视中景，切换至 @Image2 构图，画面中央浮现一朵完整的白栀子花；
花瓣边缘随空气轻微外翻舒展...

镜头 3（跟随段 3）：固定中景，在白栀子花周围伸出 3-4 片深绿蜡笔叶（沿用 @Image3 造型）...

末尾约束：
无水印，无背景音乐。
```

### 修复要点

| 修复点 | 详细 |
|---|---|
| **指令位置** | 装饰字保留从"每个镜头散落写"提升到【主体和视觉基底】段 1 |
| **指令措辞** | "**自始至终保留**...**持续贯穿不淡出**"（强调全局属性而非单镜头指令） |
| **位置锁定** | "**固定在画面顶部居中位置**"（避免 seedance 自由发挥把字放别处） |
| **冗余删除** | 镜头 2/3/收尾里 3 次重复的"顶部居中保留..."全部删除 |
| **末尾约束删字** | 末尾约束不再写"保留装饰字"——只保留"无水印，无背景音乐" |

### 实测结果

✅ verify_prompt.py 全绿
✅ seedance 任务 `cgt-20260719141536-lxx8j` 成功（4.32MB / md5=2dde8781...）
✅ 抽帧 frame_02（@Image2·白栀子花）：装饰字完美呈现 ✅
⚠️ frame_03（@Image3·花+叶 12s 收尾段）：装饰字仍部分淡出（seedance 末段自由发挥剩余空间有限）
✅ **用户原话**："OK 第二个 clip 里装饰字有了"

**教训：seedance 在 12s 短视频末尾仍有不可控淡出概率，但镜头 1-N-1 段的装饰字 100% 保留**。

## 3. 通用检测规则（v5.0.18 硬约束 #8）

### 3.1 触发场景

当 clip 满足以下**任一**条件时，装饰字保留指令**必须**写在段 1【主体和视觉基底】，禁止散落在镜头段或末尾约束：

1. Clip 包含 **≥2 张参考图**，且 ≥2 张含**同一种装饰性文字**（如"gardenia"+"栀子花"在 @Image1/2/3 都出现）
2. 任意参考图含**装饰性文字元素**（彩色字母 / 中英文黑体字 / 注音符号等），且 clip 时长 **≥8s**（seedance 自由发挥时间窗越大，淡出风险越高）
3. clip 包含 **≥3 个镜头**（镜头切换点 ≥ 2 个 = 每次切换 seedance 都倾向淡出）

### 3.2 装饰字保留指令模板

```text
【主体和视觉基底】
...（主体描述）

**画面元素：自始至终保留参考图中的"{X1}"彩色字母与"{X2}"中文字作为画面装饰元素，
固定在画面{位置}（如"顶部居中"），持续贯穿不淡出。**
```

### 3.3 反模式

| ❌ 反模式 | 后果 |
|---|---|
| 装饰字只写在镜头 1（开篇） | 镜头 2/N 自动淡出 |
| 装饰字散写在每个镜头段内 | seedance 视为"局部指令" → 镜头切换时淡出 |
| 装饰字写在末尾约束段 | 末尾约束只能锚定最后一段，前段丢失 |
| 装饰字指令无位置锁定（"出现在画面某处"） | seedance 自由发挥挪位置/变小变淡 |
| 装饰字指令无"自始至终保留..." | seedance 理解为"启动时出现"而非"贯穿" |
| 用"切换至 @ImageN 构图"覆盖装饰字 | seedance 把构图切换理解为"画面元素重新加载" = 装饰字消失 |

## 4. Step 2 vision 自检阶段（配合硬约束 #8）

### 4.1 文字元素分类（在 image-inventory.md 里标注）

| 类型 | 示例 | 是否需要保留指令 |
|---|---|---|
| **画面内装饰性文字** | "gardenia"+"栀子花"（顶部居中） | ✅ 必须 + 提升到段 1 全局规则 |
| **绘本标题/作者名** | "安徒生童话"+"Hans Christian Andersen" | ✅ 必须 + 全程保留 |
| **数字/计数标识** | "1·2·3·"（绘本计数标注） | ⚠️ 看剧情需要 = 决定是否保留 |
| **背景纯装饰花纹** | 树枝纹理/波浪线（无字） | ❌ 不归本规则（参考图 #26 范畴） |
| **页面装饰框** | 圆框/边角花纹 | ⚠️ 看风格需要 |

### 4.2 文字元素列表示例（写到 Step 2 image-inventory.md 输出）

```markdown
## 文字元素列表

| @Image | 装饰字（位置/颜色/字体） | 是否全程保留 |
|---|---|---|
| @Image1 | "gardenia"+"栀子花" 顶部居中 / 彩色字母+深蓝黑体 | ✅ |
| @Image2 | "gardenia"+"栀子花" 顶部居中 / 彩色字母+深蓝黑体 | ✅ |
| @Image3 | "gardenia"+"栀子花" 顶部居中 / 彩色字母+深蓝黑体 | ✅ |
```

### 4.3 自动化建议（verify_prompt.py R13 · v5.0.18 后续）

可以在 `scripts/verify_prompt.py` 加 R13 检查项：
- 检测 prompt 是否含装饰字保留相关关键词（如"装饰字"/"黑体"/"gardenia" 等参考图特定字符串）
- 若含 → **必须**在【主体和视觉基底】段（段 1）出现至少 1 次"自始至终保留"+位置锁定关键词
- 若装饰字保留只出现在镜头段或末尾约束 → FAIL R13（违规但允许自动改写）
- 若装饰字保留出现在段 1 但无"自始至终/贯穿"措辞 → WARN R13

但目前 v5.0.18 阶段**靠 Step 2 视觉自检 + Step 5 模板手写**防护，R13 脚本待补。

## 5. 跟其他案例的对照

| 案例 | 触发条件 | 修复方式 |
|---|---|---|
| #26 参考图是起点不是限制 | 参考图跟 prompt 描述不一致 | 按参考图写，不是反过来 |
| #36 末尾约束分 2 类 | 参考图含装饰性文字 | 末尾约束仅写"无水印无背景音乐"+ 镜头段写"保留..." |
| #37 画面静止 | 段 2 只写运镜没写主体动作 | 加主体动作关键词 |
| #39 朝向过渡 | 多图朝向不一致 + 没写旋转 | 衔接镜头写旋转动作 |
| **#40 装饰字淡出** | **多图含装饰字 + clip ≥8s** | **装饰字指令提升到段 1 视觉基底（全局规则）** |

**#40 是 #36 的强化版**——#36 规定"末尾约束只能 2 项（无水印无背景音乐），装饰字保留写在镜头段"，但 #40 发现这种分散写法的实战失败率 = 镜头切换时装饰字淡出。修复策略从"分散镜头写"升级到"提升到段 1 全局规则"。

**#40 是 #26 的子集**——都是"参考图细节如何贯穿整个 clip"问题。#26 关注"主体一致性"，#40 关注"装饰元素一致性"。

**#40 跟 #39 互补**——#39 解决多图主体朝向硬翻，#40 解决多图装饰元素淡出。两类 BUG 模式都属于"多图 clip 切换时的视觉断裂/丢失"。
