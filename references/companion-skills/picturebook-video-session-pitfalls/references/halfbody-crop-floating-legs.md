# 半身参考图转9:16 → 模型自由补画下肢→悬浮定格（庆祝类措辞高危）

案例：医生批次 clip8（2026-08-31，工作目录 /tmp/pb_video4，成片 final_doctor.mp4 32.8s）。

## 现象
- clip8 = 医生男孩面对面击掌 + 色块背景（参考图 8.jpg）。用户反馈成片最后一个画面小孩"悬浮在空中"。
- 参考图 8.jpg 是**横版半身构图**：两人腰部/胯部裁切，医生与男孩的双腿双脚完全不可见，男孩仅露一小条蓝裤腰；背景纯色块，无地面、无影子。**"着地与否"在参考图内没有依据。**
- 成片 9:16 中模型**擅自补画全身**：男孩屈膝小腿后收（跳跃定格姿势），双脚悬空——低位脚距画面底边约 500px（0.4×帧高），高位脚约 570px。
- 0.5s 步进 9 帧逐检：**t=0.0→4.0 无一帧落地**，帧间脚位差仅 ±20-30px，无起跳-下落轨迹，无影子无地面 → 是**静止悬浮定格**，不是跳跃瞬间。
- 诱因：prompt_clip8 段1 写"击掌**庆祝**场景"——庆祝/击掌/开心类措辞诱导模型演绎跳跃并自补下肢。医生侧因白大褂延伸出画未受影响；唯独男孩被补了悬空腿。

## 诊断流程（已验证）
1. **定位工作目录**：`find /home/ubuntu /tmp -type f \( -name '*.mp4' -o -name '*.png' \) -newermt '<近3天>'`，结合 `医生.srt` 定位；批次常用临时目录（如 /tmp/pb_video4），易失，诊断要趁早。
2. clip8 抽帧：ffmpeg 每 0.5s 一帧 → PIL 拼 3×3 网格（左上角红底黄字标 t=Xs），同时另存底部 45-55% 裁剪版（脚部特写）。
3. vision 提问要求**逐帧**回答：脚部位置/距底边距离/有无支撑物影子/悬浮起始于第几秒/是否全程；明说"不要泛泛而谈"防幻觉。
4. 对照参考图：问同一套问题（构图景别/腿部是否可见/人物姿态），锁定"成片偏离参考图"的具体点（本例=横版半身→竖版被补全身+悬空）。
5. 全批顺检：其余每 clip 抽 t=0.2/2.0/3.8 三帧横向拼图，一次 vision 审查一个 clip，专查脚部/支撑/影子。

## 修复模板
**主方案（推荐）：写死回归参考图半身构图**——与其余 clip 统一，模型无需补下肢，根除悬浮：
- 段1 删"庆祝"字样，改写："半身构图同参考图，两人腰部以上，白大褂衣摆与男孩衣摆延伸至画面底边被裁切，**双腿双脚绝不入画**"
- 段2 改"身体直立站在地面上完成击掌"；禁词写死：**禁止跳跃、禁止悬空、禁止腾空、双脚绝不离地、绝不屈膝**

**备选（用户坚持全身时）**：双脚落地写死——双脚分开与肩同宽、全脚掌踩在画面底部约 12% 高的地面色带上 + 椭圆柔和接触阴影 + 膝盖直立不弯曲。

## 规律
**参考图被裁切掉的部位不会被 9:16 自动保留，反而会被模型自由补画。** 半身人物参考图转竖版时，prompt 必须显式声明裁切部位的处理方式（延续出画 vs 完整全身+落地+影子），缺省即模型自由发挥；"庆祝/击掌/开心"类动词是悬浮跳跃的高危诱因词。成片审查时脚部/支撑属必查项（同 物理合理性复查铁律）。

顺带：同批 clip7 红球 t≈2.0 无支撑悬空、t=3.8 发光光晕——物件级同类异常，人物无恙，不单独返工，重交互动确认时顺带确认。
