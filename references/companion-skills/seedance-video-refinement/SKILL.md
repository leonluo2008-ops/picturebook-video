# seedance-video-refinement · 视频修正流程

> 当用户反馈视频有发音/布局/文字问题时，按此流程系统化修正，避免反复踩坑。
> 2026-08-06 实测：挖掘机 8 轮迭代 + 骆驼 1 轮通过，沉淀了完整修正方案。

## 1. 中文发音修正（TTS 读错时）

**问题**：Seedance TTS 有时会把中文核心词读错声调。
- 「挖掘机」的「机」读成三声 jǐ 而非一声 jī
- 「骆驼」的「驼」读错声调

**修正方法（实测有效）**：
1. **在旁白文本中直接写拼音替代汉字**，TTS 会按拼音发音（这是唯一可靠的方法）
   - ✅ 旁白写 `wā jué jī` → TTS 读 wā jué jī（正确）
   - ❌ 只在音频描述段标注声调说明 → TTS 可能忽略，仍然读错
   - ❌ 在旁白文本中写 `挖掘机(wā jué jī)` → TTS 会把拼音也读出来，听起来更奇怪
2. 音频描述段中同时保留声调说明作为双重保障
3. 英文发音标注用 IPA + 重音位置（如 `/ɪkˈskeɪvətər/` 重音在第二个音节；`/ˈkæməl/` 重音在第一个音节）
4. **中文声调标注格式**：写为 `挖(wā)第一声、掘(jué)第二声、机(jī)第一声，注意「机」不是第三声`

## 2. 画面布局修正

**参考视频布局标准**（用户提供的参考视频 720×1280, 9:16）：
- **9:16竖屏**，720×1280
- **主体放大填满80%+画面**，左右边缘被主体裁切，上下不留空白
- **核心词在顶部**作为标题，英文在上、中文在下，格式为 `「English/中文」`
- **运镜**：从全景开始 → 缓慢推近至主体占80% → 再缓慢拉远回到全景

**prompt 段 2 标准写法**：
```
9:16竖屏。运镜从全景开始，画面显示[主体]全身和周围环境，然后镜头缓慢推近至[主体]占据画面80%以上面积，左右边缘被[主体]裁切，最后再缓慢拉远回到全景。核心词「English/中文」始终位于画面顶部作为标题。
```

**段 1 标准写法**：
```
[主体描述]（@ImageN 景别），[颜色/特征]。画面顶部有彩色「English/中文」装饰文字作为标题。
```

## 3. 核心词格式硬规则

- 每个画面**只保留一组** `「English/中文」` 装饰文字
- ❌ 错误：`「EXCAVATOR」字母和「挖掘机」中文装饰文字`（两组分开）
- ✅ 正确：`「EXCAVATOR/挖掘机」装饰文字`（一组合并）
- 保留行也统一为一组：`保留参考图中的「excavator/挖掘机」文字作为画面装饰元素`

## 4. 修正工作流

1. **用户反馈问题** → 先读当前 prompt 确认问题根因
2. **一次性修完所有 clip 的同类问题**（不要只修一个，用户会反复打回）
3. **重新生成视频**
4. **发用户确认**

## 4.5 发音修正重做 → 画面文字退化（必须重验）

**现象（2026-08-27 卷心菜实测）**：为修多音字「卷」（卷心菜 juǎn，TTS 误读）把段 3/段 5 旁白改拼音 `juǎn xīn cài` 后重做 Clip，**音频对了但画面文字退化**：
- 图2 英文小写 `cabbage` 被画成大写 `CABBAGE`（大小写漂移——seedance 重生成有随机性、倾向复制相邻图大小写）
- 图7 旁白词「好吃的」泄漏进画面当标题、英文 `cabbage` 丢失 → 变「好吃的卷心菜」

**根因**：seedance 每次重生成都重画整套画面（随机），句首修饰旁白词（好吃的/炒/长在…）惯犯式进画面——与 `seedance-prompt-pitfalls` 陷阱 #1/#2 同类。

**处理**：
1. **重做后必须把「画面文字保真」当独立验收项**重新 vision 抽多帧核对（英文大小写逐图保真 + 中文核词 + 无多余行 + 无旁白词泄漏），**不能只听音频就通过**。
2. **段 2 镜头粒度锁字**（最可靠）：给每个镜头补
   `本镜头顶部文字只保留@Image{N} 的{小写/大写 EN} + 一行"{CN}"，仅两行，禁止出现"{句首旁白词}"写入画面。`
3. 末尾约束强化 `旁白词（{句首修饰词}等）不得出现在画面文字中`；共享核词的多图另加 `禁止复制/叠加成两组重复文字`。
4. 改拼音重做 1 次仍被旁白词顽固污染 → 回退陷阱 #2（旁白用 MiniMax TTS 独立生成）。

## 5. 常见修正场景速查

| 问题 | 根因 | 修正方法 |
|------|------|----------|
| 中文发音错误 | TTS 不认识汉字声调 | 旁白文本中直接写拼音替代汉字 |
| 画面上下留白 | 参考图未放大裁剪 | 写「运镜从全景开始→推近至主体占80%→拉远回到全景」 |
| 核心词出现两组 | 分开写了英文和中文 | 合并为 `「English/中文」` 一组 |
| 画面静止不动 | 只有运镜没有主体动作 | 主体本身需要动（晃头/行走/摆动等） |
| 凝固语命中 | 用了「保持静止/持续循环」 | 改为「继续轻微晃动/摆动，保持运动状态自然过渡」 |
