# 多图 Clip 文字重复叠加修复模式（2026-08-29 画家实测）

> **触发**：多图 clip 中某镜头的文字组被**重复叠加**——同一组"artist 画家"出现两次（上下叠放或前后重叠），参考图只有一组。
> **与陷阱 #3 其它子类的区别**：不是旁白词污染标题，不是大小写叠放，而是**参考图文字被完整复制了一份**。

## 判定

Step 7 抽帧时视觉模型报告：
- "出现了上下重叠的双份文字"
- "画面中出现了两组重复叠加的文字"

注意与陷阱 #3 其它子类区分：
| 子类 | 症状 | 修复 |
|------|------|------|
| 旁白词污染标题 | 标题变成旁白词 | 陷阱 #1 约束 / 回退 #2 |
| 目标词自身叠放 | 同一位置两行完全相同的英文 | 拆 clip |
| 两图同名叠加 | 两张同核心词的图文字叠加成 3-4 行 | 文字作用域约束 |
| **文字组重复叠加（本篇）** | 参考图文字被完整复制一份 | 末尾加"每个镜头只出现一组文字，严禁重复叠加文字" |

## 修复模式

在末尾约束中追加：

```markdown
每个镜头只出现一组文字，严禁重复叠加文字。
```

**与已有约束组合**：

```markdown
无字幕、无Logo、无水印、无背景音乐。@Image1 保留大写ARTIST，@Image2 保留小写artist，
禁止大小写互相变形。每个镜头只出现一组文字，严禁重复叠加文字。
旁白词（看这位等）不得出现在画面文字中，画面只有两行文字（英文+中文），
不出现任何其他汉字，不得添加或改动任何文字。禁止生成任何额外文字或字符，
只保留参考图中已有的文字元素。
```

## 复现条件

- 多图 clip（2 张图）
- 参考图有装饰性文字
- prompt 已写"只保留参考图中已有文字元素"但仍重复

## 验证

重做后抽帧，追问视觉模型："画面中有几组文字？每组是什么？有无重复？"

## 本篇也与长 prompt 静默丢弃相关

2026-08-29 画家 clip1 原始提交时，mcp_seedance_generate_video **静默丢弃了长 prompt**（见陷阱 #17 场景 A），seedance 收到的是**无 prompt 的提交**。无 prompt 时 seedance 对多图参考的处理更不稳定 → 文字重复叠加可能是"无 prompt 生成"的副产物，不一定是"有 prompt 但约束不够强"。**排查顺序**：先确认 prompt 是否真的传到了 seedance（看 task_id 对应的 prompt 是否完整），再判断是否需要加强约束。
