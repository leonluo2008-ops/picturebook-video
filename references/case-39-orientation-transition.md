# 案例 #39 · 多参考图主体朝向 180 度硬翻 = 镜头衔接断裂

> **来源**: Crane Truck 起重机绘本 · 2026-07-09 · v5.0.17
> **根因**: 段 2 衔接镜头没写"主体原地旋转 N 度"过渡动作 → seedance 默认按 @ImageN 静态切镜 → 视觉断裂
> **修复**: 衔接镜头显式写旋转过渡（朝向差 ≥90 度必写）
> **沉淀**: 硬约束 #7 + verify_prompt.py R12 执行抓手

---

## 1. 翻车现场

### 1.1 素材

绘本《Crane Truck 起重机》Clip 1（8s, 3 镜头, 16:9）：
- @Image1：黄色起重机**朝左**，中右位置
- @Image2：黄色起重机**朝右**，中左位置
- @Image3：黄色起重机**朝右**，中左位置

### 1.2 v1 prompt（翻车版）

```
镜头 1（@Image1 + 段 1 旁白）：横移推近，起重机从画面右侧缓缓进入画面...
镜头 2（@Image2 + 段 2 旁白）：固定镜头，起重机在画面中央轻微左右摇摆，吊臂缓慢抬起约 15 度，吊钩随惯性轻摆...
镜头 3（@Image3 + 段 3 旁白）：俯冲推镜，起重机从远景逐渐推近为中景，吊臂持续向上伸高 20 度...
```

### 1.3 实测结果

✅ verify_prompt.py 全绿（无 FAIL，无 R11 空间目标问题）
✅ seedance 任务 `cgt-20260709113447-n85kz` 成功返回
❌ **用户反馈**："第 1 个镜头切到第 2 个镜头时，出现了断裂"
❌ **根因诊断**：@Image1 朝左 → @Image2 朝右，朝向差 **180 度**，seedance 默认按参考图静态切镜，主体从朝左瞬间翻转到朝右 = 视觉断裂

### 1.4 关键教训

**verify_prompt.py 全绿 ≠ 视觉无 BUG**。

R6-R12 都是文本级规则，**没有任何一条规则检查"相邻参考图主体朝向是否一致"**——这是 R1-R12 的盲区。需要在视觉阶段（Step 2）和 prompt 阶段（Step 5）双层防护。

## 2. v2 prompt（修复版）

```
镜头 1（@Image1 + 段 1 旁白）：横移推近，起重机从画面右侧缓缓进入画面，吊臂边滑行边轻微摆动，镜头方向：从右向左横移，主体位移方向：从画面右外到画面中央。
镜头 2（@Image2 + 段 2 旁白）：固定镜头，黄色起重机在画面中央原地缓慢旋转 180 度（从朝左转至朝右，吊臂边转边轻微抬升 15 度，吊钩随惯性轻摆），镜头方向：固定中景，主体位移方向：车身原地旋转 180 度，吊钩随转幅画弧线。
镜头 3（@Image3 + 段 3 旁白）：俯冲推镜，起重机从远景逐渐推近为中景，吊臂持续向上伸高 20 度，镜头方向：从上方俯冲推近，主体位移方向：吊臂顶端吊钩从画面中部向画面顶部边缘延伸至接近顶部。
```

### 修复要点

| 修复点 | 详细 |
|---|---|
| **显式旋转动作** | "原地缓慢旋转 180 度（从朝左转至朝右）" |
| **旋转伴随动作** | "吊臂边转边轻微抬升 15 度" — 避免旋转时主体僵直 |
| **位移方向重写** | "车身原地旋转 180 度，吊钩随转幅画弧线" — R11 空间目标合规 |
| **运镜保持** | "固定中景"（不引入新运镜）— R7 镜头-旁白绑定 |

### 实测结果

✅ verify_prompt.py 全绿
✅ seedance 任务 `cgt-20260709114607-sggld` 成功
✅ 用户未再反馈断裂（待进一步确认，但 prompt 已修复根因）

## 3. 通用检测规则（v5.0.17 硬约束 #7）

### 3.1 触发场景

当 clip 满足以下**全部**条件时，**必须**在衔接镜头写旋转过渡：

1. Clip 包含 **≥2 张参考图**
2. 段 2 包含 **≥2 个镜头**
3. 相邻镜头的 `@ImageN` → `@ImageN+1` **主体朝向差 ≥ 90 度**

### 3.2 朝向差分类

| 朝向差 | 处理 | 修复动作 |
|---|---|---|
| **0 度**（同向） | 无需处理 | 直接衔接 |
| **< 90 度**（小角度） | 可选 | 写"微调 N 度"或不写（seedance 自动平滑） |
| **90 度**（侧身 ↔ 正面） | **必写** | "主体原地旋转 90 度" |
| **180 度**（朝左 ↔ 朝右） | **必写** | "主体原地旋转 180 度（从朝 X 转至朝 Y）" |
| **270 度**（如背面 ↔ 正面） | **必写** | "主体原地旋转 270 度"或简化为"180 度" |

### 3.3 修复写法（4 要素）

```text
[运镜方向]：固定/横移/推近（保持稳定，不要引入新运镜）
[旋转主体]：{主体}在画面{位置}原地缓慢旋转 N 度
[旋转方向]：（从朝 X 转至朝 Y）
[伴随动作]：{吊臂/头部/尾巴} 边转边 {轻动/抬升/下垂}，避免旋转时主体僵直
[位移方向]：{主体位移方向}（R11 空间目标合规用词）
```

### 3.4 反模式

| ❌ 反模式 | 后果 |
|---|---|
| 衔接镜头没写旋转 → seedance 静态切镜 | 朝向 180 度硬翻 = 视觉断裂 |
| 写"主体转身"没指定角度 | seedance 自由发挥 = 不可控 |
| 写"主体快速旋转 360 度" | 转过头 = 比断裂更糟 |
| 旋转时主体僵直无伴随动作 | "机器人感" = 不像手绘绘本 |
| 引入新运镜（推近+旋转同时） | 双动叠加 = 镜头混乱 |

## 4. 跨图比对方法（Step 2 vision 自检阶段）

### 4.1 朝向编码标准

| 编码 | 朝向 |
|---|---|
| **L** | 朝左（车头/面部朝画面左边） |
| **R** | 朝右 |
| **F** | 正面（朝向镜头） |
| **B** | 背面（背对镜头） |
| **LF/LB/RF/RB** | 左前方/左后方/右前方/右后方 |

### 4.2 朝向一致性矩阵（写入 image-inventory.md）

```markdown
## 朝向一致性矩阵

| @Image | 朝向 | 景别 | 位置 | 与上一张差 | 需旋转过渡 |
|---|---|---|---|---|---|
| @Image1 | L | 中景 | 中右 | - | - |
| @Image2 | R | 中景 | 中左 | 180 度 | ✅ 必写 |
| @Image3 | R | 中景 | 中左 | 0 度 | ❌ 同向 |
```

### 4.3 自动化建议（v5.0.18 后续）

可以在 `scripts/verify_prompt.py` 加 R12 检查项：
- 解析所有 `镜头 N（@ImageN + 段 N 旁白）` 段
- 提取 `@ImageN` 序列
- 假设：相邻镜头 @ImageN 不同 = 检查该镜头正文是否包含"旋转 N 度"动词
- 若缺 → FAIL R12

但目前 v5.0.17 阶段**靠 Step 2 视觉自检 + Step 5 手写防护**，脚本 R12 待补。
