# 跨图人物退场—倒影—再入场过渡 · v5.0.19 案例 #43 修复手法

> **来源**：2026-07-15 Bridge 桥绘本实测 · 3 个 Clip 中最后一组（段 6 + 段 7 + 段 8）的连续动作衔接。

## 1. 场景特征

绘本最后 3 张图涉及同一角色（女孩）的退场 + 环境（无人桥）+ 再入场的连续叙事：

| Clip 顺序 | SRT 段 | @ImageN | 画面内容 | 关键难点 |
|---|---|---|---|---|
| Clip X | 段 6 | @ImageN | 女孩侧身走/正面在桥上 | 主体在 → 要退场 |
| Clip X+1 | 段 7 | @ImageN+1 | 无人桥 + 倒影 | 主体空 → 需要承接 |
| Clip X+2 | 段 8 | @ImageN+2 | 女孩背对镜头扶栏远眺 | 主体再入 → 不能硬翻 |

**错误做法**：3 镜头直接 `@Image6 → @Image7 → @Image8` 静态切镜 → seedance 不知道发生了什么 → 视觉断裂（女孩凭空消失又凭空出现）。

**正确做法**：用 **3 段连续动作语义化**：

```
镜头 1（@Image6 + 段 6 旁白）：女孩走出画面右侧
镜头 2（@Image7 + 段 7 旁白）：镜头跟拍后下摇到水面倒影
镜头 3（@Image8 + 段 8 旁白）：镜头从水面慢推到女孩背影
```

## 2. 三段动作细分（Bridge 实测范本）

### 镜头 1 · 退场

```
镜头 1（女孩 @Image6 + 段 6 旁白）：
侧面跟拍，女孩从画面中央迈步走向画面右侧（带出主体从中央到右侧的空间位移），
一手轻扶栏杆向前滑动，辫梢和裙摆随步伐轻摆；念完后女孩走出画面右侧，
镜头跟随并缓缓下摇到桥下水面。
```

### 镜头 2 · 倒影承接

```
镜头 2（桥与倒影 @Image7 + 段 7 旁白）：
低角度缓慢推镜，从画面底部的水纹推向画面中央的桥梁倒影；
一圈涟漪由画面中央向画面右侧扩散，倒影随波纹轻轻起伏。
```

### 镜头 3 · 再入场背影

```
镜头 3（女孩背影 @Image8 + 段 8 旁白）：
镜头从画面底部水面向上摇至画面中央的女孩背影，再由远及近缓慢推近；
女孩双手扶栏杆，身体微微前倾看向远处，辫梢和裙摆随风轻摆，
远处花草摇曳。
```

## 3. 为什么这样写有效

| 衔接点 | 视觉动作 | 节奏密码 |
|---|---|---|
| 镜头 1 → 镜头 2 | 女孩走出画面右侧 + 镜头下摇至水面 | "走出画面" + "下摇" 两个连续动作把画面焦点从人物身上推到水面 |
| 镜头 2 → 镜头 3 | 水面涟漪 → 镜头随之上摇至人物背影 | 反向 · 镜头回到人物时已是背影，**避免正面/侧面硬翻** |
| 整体动作链 | 退场 → 倒影 → 背影 → 远眺 | 4 步动作连续，构成"叙事弧"而不是 3 张静态图 |

## 4. 关键反模式（必避）

| 反模式 | 后果 |
|---|---|
| 镜头 1 写"镜头横移展示桥"（未带女孩走出画面） | 镜头 1→2 切换时女孩无退场 → 视觉上"凭空消失" |
| 镜头 2 写"镜头切到桥景"（无下摇动作） | 镜头 1→2 切换生硬 → 视频观感差 |
| 镜头 3 写"女孩在桥上"（不带"从水面慢推到背影"过渡） | 镜头 2→3 女孩凭空出现 → 重复 #42 翻车 |
| 跳过倒影只把段 7 合并到段 8 | 段 7 旁白丢失或被合并 → TTS 错位 |

## 5. 配套硬约束

- **R7 镜头-旁白绑定**：每个镜头必须显式含 `@ImageN + 段 N 旁白`，避免 seedance 错位
- **R11 镜头 4 件套**：每个镜头必须含运镜动词（下摇/横移/推近/从下摇到上摇）+ 空间目标（画面右侧/画面底部/画面中央）
- **R9 收尾不凝固**：镜头 3 末尾必须写具体微动（如"辫梢轻摆一次、裙摆轻微起伏、远处云朵继续移向画面右侧"），抽象语"保持状态"=画面凝固
