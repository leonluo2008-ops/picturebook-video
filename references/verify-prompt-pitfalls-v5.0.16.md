# verify_prompt.py 实战坑点 · v5.0.16 实测沉淀（紫罗兰绘本 2026-07-21）

> 本文档聚焦 verify_prompt.py 跑 8 段 SRT 绘本实测时反复踩的 4 个坑。每个坑 = 触发原因 + 修复示例。

## 坑 1 · R3 凝固语假阳性 — 禁止句也命中

**触发**：写段 4 收尾不凝固时，按 v8.1 模板写 `不回到任何起始状态、不写持续循环。` —— verify_prompt.py 正则 `持续.*?循环` 会命中**"持续循环"四个字**触发 FAIL。

**根因**：R3 的 `FROZEN_LANGUAGE_PATTERNS` 用 `.*?` 模糊匹配，连禁用句里的"持续循环"都中招。

**修复**：禁止句去掉"持续循环"四字，改用：
- ❌ `不回到任何起始状态、不写持续循环。`
- ✅ `不回到任何起始状态。`

**修正后状态**：4 个 Clip 全部 R3 ok。

## 坑 2 · R11 空间目标 — "画面正中" 不在关键词列表

**触发**：写镜头 1 推镜时用 `紫罗兰始终保持在画面正中不变` —— verify_prompt.py 的 `space_keywords` 列表**只含"画面中央"不含"画面正中"**，R11 FAIL。

**空间关键词白名单**（来自 verify_prompt.py L448-463）：
```
画面左侧 / 画面右侧 / 画面中央 / 画面顶部 / 画面底部 / 从左侧 / 从右侧 / 从顶部 / 从底部
由近及远 / 由远及近 / 由左 / 由右 / 穿过 / 横穿 / 飞越 / 跑过
出画面 / 跑出画面 / 飞出画面 / 走出画面 / 游出画面 / 驶出画面 / 离开镜头
镜头跟随 / 镜头横移 / 镜头跟拍
```

**修复**：
- ❌ `紫罗兰始终保持在画面正中不变`
- ✅ `紫罗兰始终保持在画面中央不变` 或 `紫罗兰从画面中央略外位置由远及近推至完全占据画面中央主体`

**R11 还要求运镜动词必写**：镜头段里必须含 `横移/推近/推镜/跟拍/俯冲/固定/平视/侧面/低角度/缓慢推/拉远/特写/全景/中景/广角/长焦/微距/升/降/摇/移` 任一。

**修正后状态**：4 个 Clip 全部 R11 ok。

## 坑 3 · sed 替换二次检查 — 替换"看似成功"实际未生效

**触发**：用 `sed -i 's/A/B/' file` 替换后 `grep -c` 计数变了，但**实际文件里 A 仍存在**（只替换了部分实例或 unicode 编码差异）。

**教训**：
1. sed 后必 `grep "A" file` 验证**实际文本**是否还有 A（不要只信 `-c` 计数）
2. sed 含中文时，特别留意全角/半角、空格、标点差异
3. 改完关键 prompt 段必重跑 verify_prompt.py 确认 ok=true，不要凭"我觉得改对了"放行

## 坑 4 · patch 工具 mode 字段强制

**触发**：连续 7 次 patch 调用失败 `patch content required`，原因是 `mode='patch'` 必须在 parameters 里显式传。

**修复**：所有 patch 调用必传 `mode="patch"` 或 `mode="replace"` + path + old_string + new_string。

**fallback**：如果 patch 反复失败，立即 fallback 到 `terminal + sed -i`，不要继续在 patch 上耗 token。

## 坑 5 · R8 段 3 缺完整旁白原文 — 3+ Clip 多段合并时必踩

**触发**（2026-07-23 集市绘本实测 · 8 段 SRT 合并 3 Clip）：写段 3 关键节点对照时，按 v8.1 蓝本写：

```
段1念"集市，MARKET！"：镜头下摇露出市集全景。
段2念"集市有摊位，market"：镜头切到摊位通道向前推近。
```

—— verify_prompt.py FAIL R8："段 3 缺完整旁白文本 — 必须用 '段 N 念\"完整旁白文本\"：动作描述' 格式列出每段旁白原文"。

**根因**：v8.1 蓝本要求段 3 必须**逐段列出完整旁白原文** + 动作映射（seedance 需要原文直接对照时间点），但 agent 习惯写成"段N念"+"动作映射"两段式，**漏了"完整旁白文本" 5 个字的关键字段**。

**修复**（必带原文完整字符串 + 引号）：
- ❌ `段1念：镜头下摇露出市集全景。`
- ❌ `段1念"开篇"：镜头下摇。`（"开篇"太短不算完整原文）
- ✅ `段1念"集市，MARKET！"：镜头下摇露出市集全景。`
- ✅ `段2念"集市有摊位，market"：镜头切到摊位通道向前推近。`

**4 段合并 Clip 的段 3 必写格式**（参考集市绘本 clip2 · 段3+段4+段5+段6）：
```
段3念"集市有水果，market"：镜头横移展示水果。
段4念"集市有蔬菜，market"：镜头下推展示蔬菜。
段5念"集市有鲜花，market"：镜头横移展示鲜花。
段6念"集市有鱼，market"：镜头横移展示鱼。
```

**判定**：R8 通过条件 = 段 3 行数 == 段数，且每行段号与 SRT 段号一一对应 + 完整旁白原文 + 动作映射。

## 坑 6 · 4 段合并 Clip 时 R8 + R11 集中踩坑（v5.0.16+ 必读）

**触发**（2026-07-23 集市 clip2 实测 · 4 段旁白+4 张图合并到 13s 单 Clip）：SRT 段数多 → clip_merger 自动合并相邻段 → 单 Clip 内 4+ 段 = 同时触发 R8（段 3 必逐段列完整旁白）+ R11（每个镜头必带空间目标）。

**集中修复套路**（clip_merger 输出 N 个 Clip 后必走）：

1. **R8 必写完整段 3**（坑 5 写法）—— 4 段合并 = 段 3 必须 4 行
2. **R11 每个镜头必带空间目标**（坑 2 关键词白名单）—— 4 段合并 = 段 2 必须 4 个镜头 + 每个镜头末尾写"从画面 X 边缘向画面 Y 边缘移动"或"从画面顶部向画面底部推近"
3. **段 1 必描述每张参考图视觉基底**（R6）—— 4 段合并 = 段 1 必须 4 个"画面N（@ImageN）："块
4. **段 4 末尾镜头必带具体微动**（R9）—— 不可用"回到开场状态"等抽象语

**集市绘本 clip2 修复对照**（4 段合并的实际踩坑 → 修复示例）：
```
# 错误版（3 处违规）
镜头1（@Image3 + 段3旁白）：镜头横移展示水果。

# 正确版（R6 + R7 + R8 + R11 全过）
镜头1（@Image3 + 段3旁白）：镜头从水果特写（@Image3）从画面左侧向画面右侧缓缓横移（运镜：横移），
镜头依次经过苹果红、香蕉黄、葡萄紫、桃子粉，水果在画面中依次流动，Market集市文字保留在画面顶部。
镜头从画面左侧边缘向画面右侧边缘移动。
```

**4 段合并的最小修复 = 5 个动作**：
1. 段 1 加 `画面N（@ImageN）：视觉基底描述` 块（N 个）
2. 段 2 每个镜头末尾加 `从画面X边缘向画面Y边缘移动` 或 `从画面X向画面Y推近`
3. 段 3 改成 `段N念"完整旁白"：动作映射` 格式（N 行）
4. 段 2 每个镜头末尾加运镜动词（横移/推近/跟拍/俯冲/固定/摇/移 任一）
5. 段 4 末尾镜头改"保持 X 微动"等具体微动描述，不用抽象语
