# 竖版参考图工作流（v5.0.20 新增 · 2026-09-01 农民批实测沉淀）

> 用户拍板的根治路径：横版素材 → 竖版视频时，**在源头把参考图生成为真 9:16**，而不是让 seedance 裁剪或做画布预合成。

## 1. 为什么（三方案实验结论 · 2026-09-01）

Seedance 官方「图片裁剪规则」：ratio 与图片宽高比不一致时，方舟对参考图**居中真裁剪**。

1920×1200 横图喂 9:16 → 只保留中间 ~675px 竖带，带外像素模型根本看不见。

| 方案 | 实测结果 | 结论 |
|---|---|---|
| A. 提示词层（强指令保留全部内容） | ❌ 带外元素（木推车）仍消失，模型看不见的像素救不回 | ❌ 无效 |
| B. 预合成 9:16 画布（横条居中+模糊延展带） | 推车回来了，但用户否决：「和横版没区别」竖版空间没用起来 | ❌ 禁用 |
| C. **源头竖版：反推提示词 → 即梦出真 9:16 图 → 直喂** | 内容零裁剪，8/8 clip 一次过，零返工 | ✅ **标准流程** |

## 2. 流程（插入位置 = Step 1.5，横版素材触发）

**触发条件**：用户给的参考图是横版（宽>高）且目标输出是竖版 9:16。

1. **Step 1.5a · 逐图 vision 反推**：对每张横版图提全部视觉要素（主体外观锚点/动作姿态/道具/背景/标牌样式/文字精确内容颜色/画风笔触）
2. **Step 1.5b · 提炼全局外观锚点**：角色跨页一致的特征（发型/帽/衣/裤/鞋/表情风格），写进每张图的提示词共用块
3. **Step 1.5c · 产出竖版生图提示词文件**（交用户去即梦批量生成）：
   - 格式：L4 四字段（旁白/比例/页面类型/生图提示词）+ 全局约定（风格/外观锚点/文字控制警告）+ 场景锚点
   - **字符硬上限 2000**（用户要求，实测 1491 通过）；精简策略 = 每图一句话密度，保外观锚点/标牌样式/构图策略
   - 竖构图策略：天空上/草地下/标牌移上部居中/前景元素放下带，**内容不变只变构图**
4. **Step 1.5d · 交付后用户回传竖版图包** → 从 Step 2 正常继续（vision 自检用竖版新图）

## 3. 反推后必须做的两个核对（2026-09-01 踩坑）

1. **图↔旁白一致性**：每页画面必须与该页旁白基本一致（农民批 2.jpg/4.jpg 原始素材就重复——都画坐拖拉机，旁白却是「来了」vs「开着」，反推照抄会放大这个雷）
2. **场景唯一性**：全部页互不重复；动作可相似但核心场景必须不同（扛锄走路 vs 拄锄眺望 OK；两页都坐拖拉机 = 重复，必须重设计其中一页）

## 4. 视频阶段注意（v2 批实测）

- 竖版真图直喂，prompt 段 1 注明「竖版9:16，完整使用，无需裁剪」
- 首帧集成瞬态：frame0 可能轻微放大致边缘元素裁切，仅单帧 ~42ms，0.4s 起恢复正常 → **无需返工**（重摇同样存在）
- 其余流程（SRT 解析/clip 划分/火锅 prompt/提交/拼接）与标准 7 步完全一致
