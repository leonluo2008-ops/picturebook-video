## 一、R8 关键字硬编码(2026-07-09 实测)

`scripts/verify_prompt.py` 的 R8 检查用正则 `段\s*\d+\s*念[""""'".]`。

**只认关键字"段 N 念"**,不认:
- ❌ `句 N 旁白`
- ❌ `句 N 念`
- ❌ `Segment N`
- ❌ `clip N`

**正确写法**:

```
段 3 · 关键节点对照(按事件分镜 · 不写精确时间戳):
段 1 念"妈妈 MOTHER!":镜头 1 仰角推近。
段 2 念"看,这是妈妈":镜头 2 横移到妈妈特写。
```

**错误写法**(FAIL R8):

```
句 3 · 关键节点对照(按事件分镜 · 不写精确时间戳):
句 1 念"妈妈 MOTHER!":镜头 1 仰角推近。
```

## 二、R11 空间目标关键字硬编码(2026-07-09 Crane Truck 实测)

R11 检查用关键词白名单正则。**只认**:
- ✅ 画面左/右/中/顶/底
- ✅ 从/由/穿过/出画面
- ✅ 跑出/飞出/走出/消失
- ✅ 镜头跟随/横移/跟拍
- ✅ 由近及远/由远及近

**不认**(FAIL R11):
- ❌ 画面上沿/下沿/左缘/右缘
- ❌ 接近XX边缘
- ❌ 画面内方向
- ❌ 上方/下方/左边/右边(必须是"画面左""画面右"+"画面"前缀)

**修复策略**:避开同义词,用脚本认识的词。

| 错误写法 | 正确写法 |
|---------|---------|
| 画面上沿 | 画面顶部 |
| 接近顶部边缘 | 接近顶部 |
| 画面下沿 | 画面底部 |
| 画面的左侧 | 画面左侧 |

完整白名单 + 黑名单对照表见 `references/four-piece-shot-spec-v5.0.16.md §10`。

## 三、应急检查清单(写完 prompt 跑 verify 之前自查)

### R8 段 3 自查

- [ ] 段 3 是否用了"段 N 念"格式(不是"句 N 念")
- [ ] 每行"段 N 念"后面是否跟完整引号包裹的旁白原文
- [ ] 旁白原文是否跟 SRT 段一致(不要意译/简化)

### R11 段 2 自查

- [ ] 每个镜头段是否含运镜动词(横移/推近/跟拍/俯冲/固定/中景/全景/特写)
- [ ] "主体位移方向"是否用了脚本认识的词(画面顶部/底部/左/右/中,出画面,穿过中央)

### R3 段 4 自查

- [ ] 收尾是否用了"保持稳定""持续循环""持续摆动"等凝固语
- [ ] 收尾是否含具体微动描述(手部动作/表情变化/环境元素动态)

### R7 段 2 自查

- [ ] 每个镜头段是否含 `@ImageN + 段 N 旁白` 绑定(不能只有"镜头 1"无 @ImageN 绑定)
- [ ] 镜头数量 ≤ 参考图数量

## 四、用户偏好(2026-07-09)

> "严禁自作主张改脚本"

虽然脚本关键字硬编码 = 设计缺陷,但**只改 prompt 不动脚本**(最小改动原则)。

如果一定要扩展关键字白名单 = 必须先跟用户确认 → 再修改 verify_prompt.py → 跑双向测试(旧 prompt FAIL + 新 prompt PASS)→ 同步更新本 reference。
