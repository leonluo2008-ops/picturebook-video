# 案例 #39 · v5.0.16 R11 镜头 4 件套翻车（运镜/空间目标必填）

> **触发**: v5.0.16 起任何 v8.1 段 2 prompt 必检 R11 = 每镜头段必含"运镜动词 + 空间目标"，否则 verify_prompt.py 报 FAIL。Gardenia 项目 2026-07-19 实测：failures=5 起步，经 4 轮修复才全过。

## 翻车场景

**Gardenia 初次写 3 个 v8.1 prompt**（沿用 ear 项目 v5.0.10.1 写法），verify_prompt.py 输出：

```
Clip 1: 5 failures（4× R11 镜头缺件 + 1× R8 段 3 缺完整旁白）
Clip 2: 5 failures（同上 + R8）
Clip 3: 6 failures（同上 + 2× R11 镜头 3 缺空间）
```

## R11 三类 FAIL 根因（踩坑记录）

### FAIL 1 · 段 3 缺完整旁白原文（R8）
- **旧 v5.0.10.1 写法**：`念到"栀子花 GARDENIA"时装饰字淡入`（只写关键词）
- **v5.0.16 R8 要求**：`段 N 念"完整旁白文本"：动作描述` 格式列出每段旁白原文
- **修复**: 段 3 全部改成 `段 1 念"栀子花 GARDENIA！"：镜头 1 启动...` 句式

### FAIL 2 · 镜头段缺运镜动词（缺件 1）
- **白名单 keywords**（中英双语）：横移/推近/推镜/跟拍/俯冲/固定/平视/侧面/低角度/缓慢推/拉远/特写/全景/中景/广角/长焦/微距/升/降/摇/移 + 英文 tracking shot / pan / tilt / zoom in/out / dolly / fixed camera / static shot / wide shot / close-up / medium shot 等
- **典型翻车**：`特写一片深绿蜡笔叶，叶面蜡笔高光闪烁` ← 缺运镜动词
- **修复**: 写成 `侧面特写，特写一片深绿蜡笔叶，叶面蜡笔高光闪烁` ← "侧面特写" 是运镜关键词

### FAIL 3 · 镜头段缺空间目标（缺件 3）
- **白名单 keywords**（v5.0.16 严格白名单）：
  - 画面内方向：画面左侧/画面右侧/画面中央/画面顶部/画面底部/画面左/画面右
  - 起讫方向：从左侧/从右侧/从顶部/从底部/由近及远/由远及近/由左/由右/穿过/横穿/飞越/跑过
  - 出画面：出画面/跑出画面/飞出画面/走出画面/游出画面/驶出画面/离开镜头/消失于/消失
  - 镜头位移：镜头跟随/镜头横移/镜头跟拍
- **典型翻车词（不在白名单）**：
  - ❌ `花盆底部` （只"底部"不在白名单，要"画面底部"）
  - ❌ `画面上边缘`（只"画面左侧/右侧/中央/顶部/底部"在白名单）
  - ❌ `由画面底部向上回中`（"向上回中"是无效补充，必须包含白名单词如"画面底部"或"由画面底部向上移"）
  - ❌ `原位微动`/`原地抖动`（无空间目标 = 必 FAIL）
- **修复**: 把所有空间描述都改成白名单词组合

## 镜头段匹配陷阱（脚本逻辑）

verify_prompt.py 的 `镜头\s*(\d+)\s*[（(]` 正则匹配**所有**"镜头 N"开头的段，包括"镜头 N（收尾）"，因此：
- 3 镜头 + 1 收尾 = 4 个独立镜头段都要通过 R11
- 收尾段**也必须**含运镜+空间目标，不能光写"保持运动状态自然收尾"
- 修复模板: `镜头 3（收尾）：固定中景，...; 镜头极缓由近及远揭示整体造型后保持运动状态自然收尾。`

## 修复模板

```markdown
【主体动作序列】
镜头 1（跟随段 N）：<运镜关键词>，<主体描述>，<空间目标关键词>。

镜头 2（跟随段 N）：<运镜关键词>，<主体描述>，<空间目标关键词>。

镜头 3（跟随段 N）：<运镜关键词>，<主体描述>，<空间目标关键词>。

【关键节点对照】
段 N 念"完整旁白文本"：镜头 N 启动，<动作描述>。

【收尾】
镜头 3（收尾）：<运镜关键词>，<主体描述>；<空间目标关键词>保持运动状态自然收尾。
```

## 检测信号

- verify_prompt.py 报 `FAIL R11: 镜头 N 缺运镜` → 镜头段首句未含运镜关键词
- verify_prompt.py 报 `FAIL R11: 镜头 N 缺空间目标` → 镜头段无白名单空间词
- verify_prompt.py 报 `FAIL R8: 段 3 缺完整旁白文本` → 段 3 写"念到 X 词时"格式而非"段 N 念"完整格式

## 一句话口诀

**运镜 + 主体 + 空间目标 + 段 3 完整旁白 = R8+R11 全过**。
